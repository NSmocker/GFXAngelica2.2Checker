GBK (code page 936) для старих програм у Windows

Ці кроки налаштовують системну локаль для старих не-Unicode програм, зокрема рушія Angelica, який обробляє шляхи через ANSI char*.

Мова інтерфейсу Windows не зміниться. Системна локаль для не-Unicode програм окрема від мови меню та вікон Windows. Зміна впливає на всі старі програми, які використовують системну ANSI-кодову сторінку.

1. Змініть системну локаль для старих програм

  1. Відкрийте меню «Пуск», знайдіть і запустіть Панель керування.
  2. Відкрийте Годинник і регіон → Регіон (або натисніть Win+R, введіть intl.cpl і натисніть Enter).
  3. Відкрийте вкладку Адміністративні.
  4. Натисніть Змінити мову системи… / Change system locale….
  5. Виберіть Chinese (Simplified, China) / Китайська (спрощена, Китай).
  6. Якщо встановлено прапорець Beta: Use Unicode UTF-8 for worldwide language support, зніміть його. Для цієї перевірки потрібен ACP 936, а не UTF-8 65001.
  7. Підтвердьте зміни та перезавантажте комп’ютер, якщо Windows цього попросить.

2. Перевірте налаштування після перезавантаження

Відкрийте PowerShell і виконайте:

Get-WinSystemLocale
Get-Culture

Add-Type -TypeDefinition @'
using System.Runtime.InteropServices;
public static class Win32LocaleCheck {
    [DllImport("kernel32.dll")]
    public static extern uint GetACP();
}
'@
[Win32LocaleCheck]::GetACP()
  • Get-WinSystemLocale має показати zh-CN або китайську локаль із code page 936.
  • Get-Culture показує культуру саме поточного процесу/користувача. Вона може бути, наприклад, uk-UA і не є доказом активного системного ACP.
  • Остання команда викликає Windows API GetACP. Для цілі цього проєкту результат має бути 936.
Важливо: результат Get-Culture та [System.Text.Encoding]::Default.CodePage залежить від процесу й версії PowerShell/.NET. Використовуйте GetACP як пряму перевірку системної ANSI-кодової сторінки.

3. За потреби змініть формат регіону окремо

Якщо потрібне саме значення культури PowerShell zh-CN, відкрийте Параметри → Час і мова → Мова й регіон → Регіональний формат і виберіть китайський формат, наприклад Chinese (Simplified, China). Це налаштування форматів дат/чисел; воно не замінює системну локаль для старих програм і не встановлює ACP 936.

4. Повторіть перевірку GFX

Після того як GetACP повертає 936, запустіть preview знову. Наприклад:

GFXAngelica2.2Checker.exe --preview --root "B:\Git\PW146RUUnpackedAssets" --gfx "gfx\npc\example.gfx"

Якщо ACP дорівнює 936, але файл усе одно не завантажується, причина може бути в самому GFX або його залежностях; правильна локаль сама по собі не гарантує успішний рендер.
